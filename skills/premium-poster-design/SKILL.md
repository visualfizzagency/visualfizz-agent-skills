# Premium Poster Design

Design posters that look like they came from a professional art director, not a template. The hero is always heavy typography; everything else supports it.

## When to use this skill

- Any social-media poster, banner, thumbnail or promo visual.
- Especially when the user says "make it look premium", "like the reference", or shares a Pinterest/Behance reference.
- When the headline is in a non-Latin script (Bangla in particular — see the differentiator section below).

## The workflow

1. **Study a reference first.** Before designing, find 2-3 beautiful posters on Pinterest or Behance in the same genre. Extract the layout DNA: where the headline sits, how the photo is treated, how many colors are used, where the CTA lives. Adapting 70-90% of a reference layout is fine — add your own touches. Never start from a blank page.
2. **Layout before decoration.** Decide the composition first: headline zone, photo/cutout zone, badge zone, CTA zone, footer. If the layout works in black and white, it will work in color.
3. **Type as hero.** The headline carries the design. If the headline is weak, no amount of decoration saves the poster.
4. **Color last, and tight.** Pick 2-3 colors maximum. One ground, one headline color, one accent. Never a rainbow.
5. **Polish.** Grain, glow, shadow, spacing. Then stop — restraint is what makes it look expensive.

## The 7 premium patterns

Pick ONE pattern per poster. Mixing patterns is how posters turn into clutter.

1. **Oversized condensed headline** — extra-bold stacked sans-serif headline over a duotone-treated photo (blue, orange or purple grade). Tight 2-3 color palette.
2. **Floating 3D icon constellation** — glossy software/app icon chips (Ps/Ai style) floating around the hero as brand shorthand.
3. **Cinematic dark** — deep navy/black ground, neon screen-glow on the photo, heavy sans headline, ONE accent color.
4. **Editorial minimal** — cream/off-white ground, one serif or italic accent word plus outline type, generous whitespace, thin rules.
5. **Gradient mesh** — green-to-blue or orange-to-pink mesh background, bold condensed type, pill-shaped CTA buttons.
6. **Cutout portrait + sticker badges** — portrait cut out in a circle or arch shape, sticker-like badge callouts (price, "Enroll Now", a benefit).
7. **Tilted diagonal composition** — rotated type blocks, floating UI chips, sticker badges, subtle grain texture.

## The premium formula

- **Restraint:** tight 2-3 color palettes, never rainbow.
- **Heavy condensed typography as the hero** — type IS the design.
- **Duotone or gradient color-grading over photography** — never raw flat photos.
- **A FEW high-gloss 3D elements**, not many cheap ones.
- **Grain texture** for a crafted finish.
- **Vary the theme color per poster.** Do not lock to one color — match the color to the topic (neon green for AI tools, deep purple for premium services, dark navy for tech). Big bold type, dark rich backgrounds.

## Typography rules

- **Headline font:** an extra-bold condensed sans, stacked over 2-3 lines. Tight leading, tight tracking.
- **One accent word** may be serif, italic, or outline type — never more than one.
- **Hierarchy is size and weight, not color.** If you need a fourth color to create hierarchy, the layout is wrong.
- **Check the render.** Always look at the actual rendered text: broken glyphs, wrong weights or clipped descenders mean the wrong font or renderer. Fix the font, never ship broken type.

## Featured differentiator: Bangla typography, done right

Most design skills ignore non-Latin scripts entirely. This one handles Bangla correctly:

- **Font: Hind Siliguri.** It covers Bengali + Latin + digits in one font. Use it for every mixed-script headline.
- **Never use Noto Sans/Serif Bengali for mixed lines.** Those fonts have NO Latin glyphs — a line like "৫TB" or "Gemini 4" renders the Latin as tofu boxes. If a headline mixes Bengali and English, it must be Hind Siliguri (or render Bengali and Latin segments with separate fonts).
- **Colloquial spoken Bangla (মুখের ভাষা, চলিত রীতি), never bookish Bangla.** Short spoken sentences, understandable in one read. Example: "ডিজাইন শিখুন, ফ্রি গাইড নিন" — not a formal textbook sentence.
- **Check conjuncts (যুক্তবর্ণ).** Render the actual text and look at it: broken or mis-shaped conjuncts mean the wrong font or a bad renderer.
- **Numbers:** use Bangla digits (১২৩) in Bangla headlines; Latin digits (123) only when the brand or product writes it that way.

## Format rules

- **Social feed images are 4:5 portrait.** No exceptions for feed posts.
- **Thumbnails are 1:1 square** (shop grids and feeds crop to square).
- **Footer on every visual:** the brand's website (for example `mdayubmondol.com`).
- **Real brand logos in real brand colors.** Never recolor a logo black to "match the theme" — a logo's real color is part of the brand. If a logo is genuinely unavailable in color, use a plain text wordmark, never a faked mark.
- **Convert AI-generated thumbnails to WebP before uploading** (smaller file size).

## What NOT to do

- Template look: centered text, stock gradient, generic icon row. If it could be any brand's poster, it is wrong.
- Rainbow palettes or more than 3 main colors.
- Bookish, formal copy in a social headline.
- Latin text inside a Noto Bengali font (tofu boxes).
- Repeating the previous poster's template — change the actual design style/layout every time.
- Tiny headline with a big empty background. The headline is the hero; give it the space.
- Black caps or hats added to a person's head in generated imagery; no black monochrome logo tiles.
