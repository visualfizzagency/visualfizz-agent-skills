# Social Caption

Every caption is simple and professional. No engagement-bait questions, no extra or fluffy words, no unnecessary names.

## The rule, in one line

If a sentence does not add information or a clear next step, delete it.

## English captions (LinkedIn, Instagram, X, Threads, Facebook)

- **Short sentences, one idea each.** Three to five lines total. Never a wall of text.
- **Structure:** hook line (what it is) → one line of value (what the reader gets) → CTA or link → hashtags.
- **No engagement-bait.** Never ask "What do you think?", "Comment below!", "Tag a friend", or any "tell us your opinion" question.
- **No fluff.** No "We are excited to announce…", "amazing news", or "just for you" padding. Say what it is.
- **No unnecessary names.** Do not name people, tools or brands unless the post is actually about them.
- **Hashtags:** at the end, 2-4 tags, never inside sentences. Every post carries its page's own hashtag set.
- **Platform length:** LinkedIn may run one line longer for context; Instagram, X and Threads stay tight.

Example (design resource post):

```
28 free Bangla PDF guides — design, AI and freelancing, completely free.
Log in and download.
resource.mdayubmondol.com/free-pdf-guides
#VisualFizz
```

## First comment

- The first comment is not a second caption. It carries what the caption deliberately leaves out: the service list, the direct link, or the offer.
- For a business/agency post, the first comment lists services briefly and ends with an inbox CTA.
- For a resource post, the first comment carries the direct download link.
- Never repeat the caption in the first comment.

## Bonus: Bangla variant (Facebook)

The same rules apply in Bangla — with one addition: use **colloquial spoken Bangla (মুখের ভাষা, চলিত রীতি)**, never bookish Bangla. Short spoken sentences, understandable in one read.

Example (same post, Bangla):

```
২৮টি ফ্রি বাংলা PDF গাইড — ডিজাইন, AI আর ফ্রিল্যান্সিং শিখুন, একদম ফ্রি।
লগইন করেই ডাউনলোড করুন।
resource.mdayubmondol.com/free-pdf-guides
#VisualFizz
```

## What NOT to do

- Engagement questions of any kind ("What do you think?", "কেমন লাগলো?").
- Fluffy openers ("We are excited to announce…", "বিশেষ খবর…").
- Hashtag stuffing or hashtags mid-sentence.
- Naming a person or brand the post is not about.
- Long paragraphs — if it needs scrolling, it needs cutting.
- Mixing languages in one caption without a reason. Pick one language per post and commit to it.
